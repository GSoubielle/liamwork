# Liamwork

Application de revision de maths pour iPad.

## Sections

- Nombres relatifs
- Priorites de calcul
- Calculs decimaux
- Complements rapides
- Divisions utiles

La progression est enregistree dans le navigateur avec `localStorage`.

## Cloudflare Worker

Le Worker sert les fichiers statiques du dossier `public`.

```bash
npm install
npm run dev
npm run deploy
```
